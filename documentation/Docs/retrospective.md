# Retrospective

## What Went Well

The project developed into a complete multi-user web application.

Important successful points:

- The application has a clear topic and purpose.
- The frontend and backend are separated.
- The project includes multiple user accounts.
- Each user has their own skills, projects and certificates.
- The admin panel can manage accounts and user data.
- The application includes documentation files.
- The project was tested with npm run build.
- GitHub branches and pull requests were used.

## What Was Difficult

Some parts were challenging during development:

- Understanding the complete project structure.
- Connecting frontend and backend correctly.
- Managing user-specific data.
- Avoiding automatic login into the wrong account.
- Protecting the admin page.
- Keeping the repository clean.
- Solving build and routing problems.

## What We Improved

The project was improved step by step:

- Login flow was cleaned.
- Dashboard became user-specific.
- Skills, projects and certificates were connected to the current user.
- Admin panel was added.
- Profile page was improved.
- Documentation viewer was added.
- README and documentation were updated.

## What We Learned

Through this project, we learned:

- how to build a Vue.js application
- how to use Vue Router
- how to manage global state with Pinia
- how to communicate with a backend API
- how to store and separate user data
- how to use GitHub pull requests
- how to document a software project

## What Could Be Improved in the Future

Possible future improvements:

- real database integration
- password hashing
- deployment
- better design customization
- file upload for certificates
- export resume as PDF
- more advanced search and filters
