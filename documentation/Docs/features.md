# Features

CareerBridge provides a complete career profile management system.

## 1. Multi-User Login

The application supports multiple user accounts.

Each user has their own data:

- skills
- projects
- certificates
- profile information
- resume data

## 2. User-Specific Dashboard

After login, each user can open the dashboard and see only their own information.

The dashboard shows:

- number of skills
- number of projects
- number of certificates
- profile progress
- recent activity

## 3. Skills Management

Users can manage their own skills.

Available actions:

- add skill
- edit skill
- delete skill
- search skills
- assign category

## 4. Projects Management

Users can manage their own projects.

Project data includes:

- title
- description
- GitHub link
- status

Available statuses:

- Planned
- In Progress
- Completed

## 5. Certificates Management

Users can manage their own certificates.

Certificate data includes:

- certificate name
- provider
- date
- link

## 6. Profile Management

Users can edit their profile information.

Editable fields:

- name
- email
- city
- professional title
- university
- GitHub profile
- professional bio
- password

The system role cannot be changed by normal users.

## 7. Resume Page

The resume page presents user career data in a structured format.

It combines:

- profile information
- skills
- projects
- certificates

## 8. Admin Panel

The admin can manage the complete platform.

Admin features:

- view all accounts
- add accounts
- edit accounts
- delete accounts
- select a user account
- manage skills for each user
- manage projects for each user
- manage certificates for each user

## 9. Documentation Viewer

The Docs page displays markdown documentation files directly inside the application.

This helps users and reviewers understand the project structure and development process.

## 10. Backend API

The backend provides API routes for:

- login
- users
- skills
- projects
- certificates
- documentation files
